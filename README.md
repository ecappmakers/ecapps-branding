# 🎨 EC Apps Central Branding & Design Authority (`ecapps-branding`)

> **Repository:** `ecapps-branding`  
> **Authority:** K.A.R.E.N. (Frontend UX) & V.I.S.I.O.N. (System Design)  
> **Purpose:** Single Source of Truth (SSOT) for all corporate logos, brand icons, color tokens, and typography definitions used across the 12 canonical EC App Makers applications.

---

## 🏛️ Brand Directory & Standards

1. **Vector SVGs First:** All official brand logos must be maintained in pristine vector SVG format for crisp rendering from 16px favicons to 4K displays.
2. **Standard Color Tokens:** Theme variables defined in [tokens/branding_tokens.json](file:///tokens/branding_tokens.json) synchronize into `ecframework/frontend/architect-ui` and client apps.
3. **Typography Invariants:** Inter & Outfit sans-serif fonts standard across the product ecosystem.
